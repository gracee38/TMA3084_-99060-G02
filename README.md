
Pizza Order Calculator

Course: TMA3084 SELAB
Lab: Lab 1

Description

A simple Dart program that calculates pizza order payments based on pizza size and quantity.

Pizza Prices
Small: USD 5
Medium: USD 7
Large: USD 10
Features
Uses a switch statement to calculate payment.
Uses a while loop for continuous ordering.
Validates pizza quantity and pizza size.
Allows the user to exit the program.
How to Run

Run the following command in the terminal:

dart run pizza_order.dart
